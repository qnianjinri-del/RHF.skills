# 万魂幡.skills

> 什么叫你这人皇幡怎么在冒token

一个专门在 GitHub 上**收魂、点魂、编号、挂牌、查重、考据**的仓库。

这里收的不是普通项目。  
这里收的是那种：

- 把同事蒸成 `.skill`
- 把前任炼成 `SKILL.md`
- 把自己导出成数字分身
- 把人格、记忆、语气、工作流、关系模式，全都封进一个可调用目录

说白了：

> 别人在做 agent。  
> 这里在做招魂。

---

## 这玩意到底是啥

`万魂幡.skills` 是一个围绕 **Claude Code / AgentSkills / OpenClaw / SKILL.md** 生态的：

- 蒸馏型 skill 索引仓
- 赛博人格考古现场
- GitHub 招魂不完全指南
- 高相似度换皮项目观察站
- 人类行为结构再封装博物馆

本仓库不负责一本正经地假装“我们在做知识管理”。

本仓库负责诚实地承认：

> 这波东西看久了，真的很像在给互联网搭人皇幡。

---

## 收的都是什么魂

目前重点关注以下几类：

### 1. 职场魂
- 同事.skill
- teammate-skill
- boss-skill
- mentor-skill

特点：
- 把甩锅方式也一起蒸进去
- 把工作流、语气、判断风格一起封装
- 人走了，魂还在 review 你代码

### 2. 关系魂
- 前任.skill
- girlfriend-skill
- 各种亲密关系分支

特点：
- 把聊天记录、照片、社交媒体、回忆都喂进去
- 试图提炼出一个“像 ta 一样回你消息”的东西
- 爱没了，prompt 还在

### 3. 自我魂
- yourself-skill
- self mirror
- digital self / persona clone

特点：
- 与其蒸馏别人，不如蒸馏自己
- 把自己的口头禅、决策习惯、深夜发疯路线图一起导出
- 最后得到一个比你还懂你的 markdown 目录

## 这仓库不干嘛

这仓库**不是**：

- 普通 prompt 大杂烩
- 通用技能市场镜像
- 看见个 skill 就嗯收
- 把别人的东西扒下来然后装成自己的

这仓库主要干的是：

### 1. 挂幡
把分散在 GitHub 上的这类项目先挂起来。

### 2. 验魂
看看它到底是不是对象蒸馏类 skill，还是只是名字起得像。

### 3. 查重
分辨：
- 谁是原始骨架
- 谁是主题平移
- 谁是模板换皮
- 谁是一眼“这味儿怎么这么熟”

### 4. 留名
保留：
- 原作者
- 原仓库
- License
- 引用关系
- 致敬链路

一句话总结：

> 收魂可以，抹碑不行。

---

## 收录原则

本仓库默认遵循四条规矩：

### reference-first
先做索引，先做目录，先做标注。  
别上来就把别人一锅端。

### attribution-first
作者是谁，仓库在哪，license 是啥，能写清楚就写清楚。  
不能搞成“魂收进来了，墓碑没了”。

### dedup-first
长得太像的，不急着都封神。  
先看看是不是一个模子里刻出来的。

### verify-before-vendor
证据不够，就先进候选池。  
别把“我感觉像”写成“我已经审完了”。

## 目前这个仓库的气质

当前阶段，`万魂幡.skills` 走的是：

> **索引流**  
> **考据流**  
> **审计流**  
> **轻整合流**

也就是说现在主要做的是：

- 记录仓库
- 看结构
- 做分类
- 分已核验 / 候选
- 为以后做相似度审计、submodule、vendor 留接口

现在还不是彻底放飞自我的“大型 GitHub 炼魂厂”。

先立幡，再添魂。
